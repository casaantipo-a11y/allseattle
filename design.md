# Правила композиции и визуальной гармонии

«Гармонично» в этом проекте значит одно: каждый размер, отступ, цвет и выравнивание
берётся из заданной системы, а не подбирается на глаз. Любое значение вне системы
считается ошибкой, даже если «так смотрится лучше».

## Приоритет относительно CLAUDE.md

**При конфликте CLAUDE.md главнее.** В нём записаны несущие факты архитектуры —
почему sticky-навигация лежит соседом `<main>`, почему пути резолвятся через
`SITE_ROOT`, порядок подключения CSS, демо-контракт «ничего не отправляется».
Нарушить их ради правила отсюда нельзя: сломается сайт, а не «стиль».

Этот файл главный во всём остальном: композиция, шкалы, иерархия, цвет, ритм.
Для нового кода он обязателен. Переписывать под него уже работающие страницы —
только по отдельной просьбе, не походя.

## 0. Порядок работы (обязательно)
1. Прежде чем писать разметку, проверь, что дизайн-токены (отступы, типографика,
   цвета, радиусы, тени) заданы в tailwind.config / CSS-переменных. Если их нет,
   создай их первыми.
2. Верстай только через токены. Запрещены произвольные значения вида
   `mt-[37px]`, `text-[19px]`, `#3a3b3c` в разметке.
3. После каждой секции пройди чек-лист из раздела 10 и явно напиши, какие пункты
   проверены. Если есть Playwright/скриншоты, сделай скриншоты 375px и 1440px
   и оцени их по чек-листу.

## 1. Сетка отступов (spacing)
- Базовый шаг 8px. Разрешённые значения: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128.
- Закон близости: связанные элементы стоят ближе, чем несвязанные.
  Отступ между группами должен быть минимум в 1.5–2 раза больше отступа внутри группы.
  Иерархия: внутри карточки < между карточками < между блоками секции < между секциями.
- Вертикальные отступы секций: desktop 96–128px, tablet 80px, mobile 56–64px.
  Одинаковые на всех секциях страницы (исключение: hero).
- **Исключение, принятое пользователем: снизу — один сантиметр.** Между двумя
  секциями и от последнего блока до подвала — 36px (1см = 37.8px, ближайшая
  сумма шагов шкалы). Числа выше про 96–128px к нижнему шву больше не
  относятся; правило живёт в `css/base.css` и `css/footer.css` и действует на
  всех страницах. Мерилось линейкой дважды (главная, новости), на третий раз
  стало общим — см. §9, «третья одинаковая правка».
- Внутренние отступы карточек: 24px (mobile), 32px (desktop), одинаковые у всех карточек.
- Заголовок ближе к своему контенту, чем к предыдущему блоку:
  отступ сверху от заголовка ≥ 2× отступа снизу.
- Положение шапки секции задано один раз в `css/components.css` (обнулённые
  отступы, надзаголовок на 16px ниже и 4px правее заголовка). Числа, замеры и
  два исключения — в CLAUDE.md. Руками шапку на новой странице не двигают.

### 1.1 Просьбы в миллиметрах
Клиент меряет линейкой по экрану, поэтому:
- Миллиметр = 3.78px. Переводим и округляем до **ближайшей суммы шагов шкалы**
  (7мм = 26.5px → 28 = 24 + 4), погрешность называем вслух в ответе.
- Названы пиксели — не округляем. Значение вне шкалы допустимо, но в CSS
  помечается комментарием: кто просил и почему это не 4/8/12.
- **Меряем видимый просвет — от края блока до букв и от букв до букв.** Не
  расстояние между коробками: у заголовка снизу ~11px интерлиньяжа, и «по
  коробкам» число выходит вдвое меньше того, что видит человек с линейкой.
- Двигается **надпись** — `position: relative`, соседи стоят на месте.
  Двигается **блок с содержимым** — отступ, соседи едут следом.
- **У каждого сдвига есть предел, и задаёт его не та ширина, на которой
  смотрит клиент.** До правки мерим запас на 375 и 1024 (там кегль мельче, а
  поля уже), называем предел в ответе и при необходимости даём телефону
  отдельный медиазапрос.

## 2. Типографика
- Число шрифтов жёстко не ограничено, но у каждого должна быть своя роль
  (заголовки / основной текст / брендовый акцент). Шрифт без функции не добавлять.
  Начертаний — максимум 3 на семейство, и грузить только реально используемые.
- Модульная шкала с коэффициентом 1.25. Базовый текст 16px (mobile) / 18px (desktop).
  Размеры: 14, 16, 18, 20, 24, 30, 36, 48, 60. Других нет.
- Заголовки на мобиле через clamp(), H1 не больше 40px на 375px.
- line-height: текст 1.5–1.7, заголовки 1.1–1.25.
- Длина строки текста 55–75 символов (max-width: 65ch). Центрированный текст не длиннее 3 строк.
- Один H1 на страницу. Уровни заголовков идут по порядку, без пропусков.
- Контраст между уровнями: соседние уровни иерархии отличаются минимум на один шаг шкалы
  и/или начертанием. Если два элемента разной важности выглядят одинаково, это ошибка.

## 3. Сетка и выравнивание
- Контейнер max-width 1200–1280px, боковые поля 16px / 24px / 32px (mobile/tablet/desktop).
- Все секции выровнены по одним и тем же краям контейнера. Никакой контент не «гуляет»
  по горизонтали от секции к секции.
- 12-колоночная сетка, gutter 24px (mobile 16px).
- В пределах одной секции одна ось выравнивания: либо всё по левому краю, либо всё по центру.
  Не смешивать.
- Элементы в одном ряду выровнены по верхнему краю или по базовой линии текста,
  карточки в ряду одинаковой высоты и одинаковой внутренней структуры.
- Раздел-перечень (новости, справочник) собирается одинаково: **одна** колонка
  до 1024 (контент первым, `order: -1`), **две** на 1024–1279 (обе боковые в
  правом столбце), **три** с 1280.
- Боковая колонка с рекламой — **300px**: нативная ширина блоков 300×250 и
  300×600. Колонка без рекламы может быть уже — 240px, как список рубрик.

## 4. Цвет
- Пропорция 60/30/10: 60% основной фон, 30% вторичные поверхности, 10% акцент.
- Один акцентный цвет. Он используется только для главных CTA, ссылок и ключевых выделений.
  Если акцента на экране больше ~10% площади, это ошибка.
- Нейтральные цвета из одной шкалы (50–950), слегка окрашенные в тон бренда, не чистый серый.
- Контраст по WCAG AA: текст 4.5:1, крупный текст и иконки 3:1.
- Чередование фона секций максимум двумя тонами, чтобы задать ритм, а не пестроту.

## 5. Визуальная иерархия
- В каждой секции одна точка фокуса (главный заголовок, изображение или CTA).
- На одном экране одна primary-кнопка. Остальные действия secondary/ghost.
- Тест «прищура»: если размыть скриншот, порядок чтения должен остаться понятным:
  что главное, что второе, что третье.
- Не больше 3 уровней визуальной важности на секцию.

## 6. Единообразие компонентов
- Радиусы: одна шкала (например 8 / 12 / 16 / full). Вложенный радиус =
  внешний радиус − внутренний padding.
- Тени: максимум 3 уровня (sm, md, lg), одинаковый источник света.
- Иконки: один набор, одна толщина линии, размеры 16 / 20 / 24.
- Кнопки: высота 40 или 48px, горизонтальный padding ≈ 2× вертикального,
  одинаковые во всём сайте для одного типа.
- Изображения: фиксированные пропорции (16:9, 4:3, 1:1) через aspect-ratio,
  одинаковые в пределах одного ряда/галереи.
- Перечень — **строка, а не карточка**: миниатюра 72px (96 с 768), текст рядом,
  описание в одну-две строки. Крупная карточка остаётся там, где есть что
  показать крупно.
- Название в строке перечня — `span`, а не заголовок: строк десятки, и полтора
  десятка `h3` подряд ломают оглавление страницы (§2, «уровни без пропусков»).

## 7. Ритм и баланс
- Повторяющиеся блоки (карточки, пункты, отзывы) строятся по одному шаблону.
- Чередование «текст слева / картинка справа» — строго по очереди, без случайных исключений.
- Пустое пространство — часть композиции. Не заполнять его декоративными элементами
  без функции.
- Визуальный вес левой и правой половины секции примерно равен.
- **Между элементами перечня рекламы нет.** Места — над перечнем, под ним и в
  боковых колонках.
- Раз эха в перечне нет, боковые баннеры видны на всех ширинах (ниже 1024
  рисуются боксом 320×100), а не прячутся на телефоне.
- Рекламные колонки уезжают вместе со страницей, а не липнут к шапке.
- **Каждое новое рекламное место называется вслух**: размер, тариф, цена.
  Инвентарь — это то, что продают, он не появляется незаметно.

## 8. Адаптивность
- Брейкпоинты: 640 / 768 / 1024 / 1280. Mobile-first.
- Никакого горизонтального скролла на 360px.
- Кликабельные элементы ≥ 44×44px.
- На мобиле многоколоночные ряды превращаются в одну колонку с сохранением
  тех же отступов из шкалы, а не с «сжатыми» произвольными.

## 9. Запреты
- Произвольные значения вне токенов.
- Больше одного акцентного цвета.
- Центрирование длинных абзацев.
- Разные отступы у однотипных секций.
- Разный стиль у однотипных компонентов.
- Декоративные градиенты, свечения и блобы «для красоты», если их не просили.
- Мёртвый код: компонент удаляется вместе с последним использованием.
- Два числа об одном и том же на одном экране. «15 businesses listed» рядом с
  «615+ Listed businesses» — ошибка, даже если оба числа честные по-своему.
  Одно число — один источник (`js/mock-data/stats.js`, `weather.js`).
- Отступление от правила без комментария в коде: кто просил, что замерено, где
  предел.
- **Третья одинаковая правка.** Пришедшее во второй раз становится правилом:
  26.09.2026 этого не сделали, и 21 коммит из 33 за день ушёл на сдвиг двух
  надписей в шапке секции.

## 10. Чек-лист после каждой секции
- [ ] Все отступы из шкалы 4/8/12/16/24/32/48/64/96/128
- [ ] Внутренние отступы групп меньше внешних минимум в 1.5 раза
- [ ] Все размеры шрифтов из шкалы, не больше 2 шрифтов и 3 начертаний
- [ ] Длина строки текста ≤ 75 символов
- [ ] Контент выровнен по краям контейнера, одна ось выравнивания в секции
- [ ] Одна точка фокуса и одна primary-кнопка
- [ ] Акцентный цвет ≤ 10% площади, контраст AA соблюдён
- [ ] Радиусы, тени, иконки, кнопки совпадают с остальным сайтом
- [ ] На 375px нет горизонтального скролла, тап-зоны ≥ 44px
- [ ] Просьбы в миллиметрах переведены в шкалу, погрешность названа вслух
- [ ] Замерен видимый просвет (буквы), а не коробки; предел проверен на 375 и 1024
- [ ] Между элементами перечня нет рекламы, новые места названы вслух
- [ ] Исключения помечены комментариями, мёртвый код удалён
